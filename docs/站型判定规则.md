# 站型判定规则（只管"这个站是不是小说站"）

> 建立日期：2026-11-14　配套工具：`scripts/probe_site_type.py`
> 背景：正式版要求"只保留纯小说"；成人段额外允许漫画/影视/视频/有声。
> 这条规则被反复用到（每次合并新源、每次清理），所以固化成文档，不再靠临场判断。

---

## 一、硬原则：不靠名字猜，只看证据

名字是最不可靠的信号。实测反例：

| 源名 | 看名字会以为 | 实际（首页 `<title>`） | 后果 |
|---|---|---|---|
| 书城书库1 | 小说书库 | 「MissKon - Asian Naked Women & Nude Photos」 | 成人写真混进非成人段 |
| 刺猬猫 | 大厂小说站 | 「漫画_在线漫画_SF漫画」mm.sfacg.com | 漫画站占着大厂名额 |
| 优品幻灯 / 优品文档 | 书源 | 「PPT模板免费下载-优品PPT」 | PPT 素材站占位 |
| 奇漫屋书2 | 漫画 | 「片多多免费在线剧情网」 | 实为影视站 |
| 听姬小说 | 小说 | 「听姬」himehear（音声/ASMR） | 音频站 |
| 哪读吧书 | 阅读站 | 「nadu.com - Coming Soon」 | 空壳站 |

**所以判定顺序固定为：`bookSourceType` → 首页 `<title>` → 域名语义**，三条不一致时以 `<title>` 为准（它反映站点当前实际内容）。

---

## 二、判定流程

```
1. bookSourceType == 0 ?
   否 → 直接进"非文本源"清单，走第 2 步
   是 → 仍需抽查（有源把类型标错，实测 14 个真小说站标成了 2/3）

2. 抓首页 <title>
   python3 scripts/probe_site_type.py --name 源名

3. 按标题归类（见 §三 特征表）

4. 处置：
   - 与阅读完全无关（PPT/档案馆/网盘/社交/音乐/播客）→ 不分段一律剔除
   - 漫画/影视/有声/音声 → 非成人段剔除；成人段保留
   - 小说（含 txt 下载站、完本站）→ 保留，type 修正为 0
   - 抓不到（403/超时/Cloudflare）→ 不猜，保留；改 type 为 0 前要有"它是小说规则"的佐证
```

## 三、站型特征表

| 站型 | 标题/域名特征（正则） | 处置 |
|---|---|---|
| PPT素材 | `PPT\|幻灯片\|模板下载\|素材\|范文\|简历\|表格模板` | **剔除**（不分段） |

| 网盘 | `网盘\|pan\.baidu\|cloud\.189\|夸克\|阿里云盘` | **剔除** |
| 社交 | `微博\|weibo\|抖音\|贴吧\|知乎\|小红书` | **剔除** |
| 音乐/播客 | `音乐\|5sing\|播客\|podcast\|荔枝fm\|电台` | **剔除** |
| 有声/音声 | `有声\|听书\|广播剧\|评书\|FM\|听姬\|音声\|ASMR` | 非成人段剔除；成人段保留 |
| 漫画 | `漫画\|漫畫\|comic\|manga\|manhwa\|webtoon\|韩漫\|日漫\|彩漫\|条漫` | 非成人段剔除；成人段保留 |

> 特征表由 `scripts/probe_site_type.py` 的 `TYPE_RULES` 实现，改规则改那一处即可。

## 五、可复用命令

```bash
# 全部非文本源（type≠0）
python3 scripts/probe_site_type.py --non-text

# 只看名字可疑的
python3 scripts/probe_site_type.py --suspect

# 单源排查
python3 scripts/probe_site_type.py --name 刺猬猫
```

结果自动落 `raw/autocollect/research/site_type_probe_<ts>.json`（工作区永久目录，不进 git 但磁盘保留）。

**注意**：抓不到 title 的源（403 / Cloudflare / 超时）不要猜类型，标"保留待人工"。宁可留着，不可误删——删掉的源用户拿不到，留着顶多占个位置。
