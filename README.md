3. 选择下载的 books.json 文件即可

## 🔍 校验流程
所有书源都经过以下四阶段校验：
1. **基础结构校验**：必填字段、URL格式、域名去重
2. **网站存活校验**：首页可达性检测（WAF盾站不淘汰）
3. **搜索接口校验**：10个关键词分两轮实测（快速过滤+精测）
4. **规则完整性校验**：详情/目录/正文规则完整性

## 🤖 自动采集脚本
本仓库内置全自动采集脚本 `autocollect.py`，可一键采集、校验、合并书源。

### 数据源池
- yckceo.com 书源列表（按月份动态采集）
- yckceo.com 书源合集（按月份动态采集）
- nyasama.net 星辰整理书源包
- 全网大佬仓库（持续补充）

### 使用方法
```bash
# 完整流程（采集→校验→整理→输出）
python3 autocollect.py

# 只采集最近3个月的
python3 autocollect.py --months 3

# 单独执行某个阶段
python3 autocollect.py --collect    # 只采集
python3 autocollect.py --validate   # 只校验
python3 autocollect.py --merge      # 只合并整理
```

### 优化特性
- **增量采集**：动态计算最近N个月，不写死
- **两级过滤**：1个词快速筛，10个词精测，节省时间
- **域名去重**：同一站多域名自动合并，保留最优规则
- **WAF友好**：403盾站不淘汰，能搜出书就保留
- **大厂保护**：12个正版大站单独保护，不被自动更新覆盖
- **自动报告**：每次跑完生成采集报告，新增/淘汰一目了然
