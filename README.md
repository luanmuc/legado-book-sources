## 📥 导入方法
1. 下载最新版 books.json
2. 打开阅读APP → 我的 → 书源管理 → 本地导入
3. 选择下载的 books.json 文件即可

## 🔍 校验流程
所有书源都经过以下四阶段校验：
1. **基础结构校验**：必填字段、URL格式、域名去重
2. **网站存活校验**：首页可达性检测
3. **搜索接口校验**：3个关键词实测搜索
4. **规则完整性校验**：详情/目录/正文规则完整性

## ✏️ 命名规范
- 全部为四字纯汉字
- 去掉表情符号和特殊字符
- 按分组+搜索通过率排序
- customOrder字段控制导入后顺序
