# 阅读书源合集

适用于 [Legado阅读](https://github.com/gedoor/legado) App 的书源合集，经过多轮校验、去重、规则补全和净化优化。

## 书源统计

- **总数**：142 个
- **头部大厂**：15 个（起点、番茄、七猫、QQ阅读、晋江、书旗、飞卢、豆瓣、纵横、17K、刺猬猫、菠萝包、轻小说文库、长佩、小说阅读网）
- **精品小说站**：75 个
- **免费小说站**：32 个
- **笔趣阁备用**：20 个

## 导入方式

1. 复制 `阅读书源_最终可用.json` 的内容
2. 打开阅读 App → 我的 → 书源管理 → 右上角 ⋮ → 导入本地 → 粘贴
3. 或直接下载 JSON 文件后选择导入

## 规则说明

- 所有源已补全搜索、详情、目录、正文四大规则
- 每个源配有专属正文净化规则（自动过滤广告、水印、网址）
- 按影响力排序：大厂优先搜索，第三方备用
- 已过滤成人、漫画、非小说站内容
